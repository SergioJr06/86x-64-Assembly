# Assembly x86-64 Architecture Studies

Estudos práticos de arquitetura de processadores e manipulação de memória utilizando Assembly x86-64. 

Este repositório documenta a implementação de lógica de baixo nível, com foco em otimização de código, gerenciamento de pilha (Stack) e convenções de chamada (System V ABI / cdecl).

## 🗂️ Estrutura do Projeto

Para manter o histórico isolado e facilitar a revisão técnica, **cada exercício foi desenvolvido em uma branch separada**. A branch `main` contém apenas este escopo geral.
